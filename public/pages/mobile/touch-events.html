    Guia do especialista

    Teste de toque não é "clicar com o dedo". O navegador espera para decidir se o gesto é rolagem, zoom ou clique, e cada plataforma decide de um jeito. Estes são os pontos que mais geram bugs.

    Touch, Pointer ou Mouse?

    • Touch Events (touchstart…) só existem com tela de toque. É o que a área de cima usa: no desktop ela não responde ao mouse.
    • Pointer Events unificam dedo, mouse e caneta. Leia event.pointerType para saber a origem.
    • Depois de um toque, o navegador ainda dispara eventos de mouse "de compatibilidade" e click. Handlers nos dois mundos executam a ação duas vezes.

    O atraso do toque

    • Navegadores antigos esperavam ~300 ms para descobrir se era um toque duplo (zoom). Com <meta name="viewport" content="width=device-width"> esse atraso não existe nos navegadores atuais.
    • touch-action: manipulation também desliga o zoom por toque duplo naquele elemento.
    • Teste: meça o tempo entre o toque e a reação visual. Acima de 100 ms já é perceptível.

    Alvos de toque

    • WCAG 2.2 (2.5.8, AA): pelo menos 24 × 24 px CSS, ou espaço livre ao redor equivalente.
    • Plataformas: 44 × 44 pt (Apple) e 48 × 48 dp (Material Design).
    • Meça com o auditor da página Responsividade.

    Armadilhas comuns

    • Listener de touchmove sem { passive: true } deixa a rolagem travando.
    • preventDefault() no touchstart mata a rolagem e o clique do elemento.
    • Gesto que funciona no emulador do DevTools e falha no Safari do iPhone: sempre valide em aparelho real.
    • Toque longo abre o menu de contexto do sistema (copiar, salvar imagem) e interfere no gesto.

    Automatize

    Emula um Pixel 7 (hasTouch e isMobile ligados). tap() gera eventos de toque reais; para swipe, o Chromium aceita toques diretos pelo protocolo do DevTools (CDP).

    import { test, expect, devices } from '@playwright/test';

test.use({ ...devices['Pixel 7'] });

test('toque registra touchstart e touchend', async ({ page }) => {
  await page.goto('/pages/mobile/touch-events.html');
  await page.getByTestId('touch-area').tap();
  await expect(page.getByTestId('touch-log')).toContainText('touchstart');
  await expect(page.getByTestId('touch-log')).toContainText('touchend');
});

test('swipe para a esquerda', async ({ page, context }) => {
  await page.goto('/pages/mobile/touch-events.html');
  const area = page.getByTestId('swipe-area');
  await area.scrollIntoViewIfNeeded();
  const box = (await area.boundingBox())!;
  const y = box.y + box.height / 2;

  // Chromium: toques sintéticos via CDP (touchStart -> touchMove -> touchEnd)
  const cdp = await context.newCDPSession(page);
  await cdp.send('Input.dispatchTouchEvent', { type: 'touchStart', touchPoints: [{ x: box.x + box.width - 20, y }] });
  for (let i = 1; i <= 5; i++) {
    const x = box.x + box.width - 20 - (i * (box.width - 40)) / 5;
    await cdp.send('Input.dispatchTouchEvent', { type: 'touchMove', touchPoints: [{ x, y }] });
  }
  await cdp.send('Input.dispatchTouchEvent', { type: 'touchEnd', touchPoints: [] });

  await expect(page.getByTestId('swipe-direction')).toContainText('Left');
});

    TouchAction está obsoleto desde o java-client 8 e foi removido nas versões seguintes. O padrão atual são as W3C Actions com um ponteiro do tipo toque.

    import org.openqa.selenium.interactions.PointerInput;
import org.openqa.selenium.interactions.Sequence;
import org.openqa.selenium.interactions.Pause;
import java.time.Duration;
import java.util.List;

PointerInput dedo = new PointerInput(PointerInput.Kind.TOUCH, "dedo");

// Swipe da direita para a esquerda
Sequence swipe = new Sequence(dedo, 0)
    .addAction(dedo.createPointerMove(Duration.ZERO, PointerInput.Origin.viewport(), 320, 600))
    .addAction(dedo.createPointerDown(PointerInput.MouseButton.LEFT.asArg()))
    .addAction(dedo.createPointerMove(Duration.ofMillis(250), PointerInput.Origin.viewport(), 60, 600))
    .addAction(dedo.createPointerUp(PointerInput.MouseButton.LEFT.asArg()));
driver.perform(List.of(swipe));

// Toque longo: aperta, espera 800 ms e solta
Sequence toqueLongo = new Sequence(dedo, 0)
    .addAction(dedo.createPointerMove(Duration.ZERO, PointerInput.Origin.viewport(), 200, 400))
    .addAction(dedo.createPointerDown(PointerInput.MouseButton.LEFT.asArg()))
    .addAction(new Pause(dedo, Duration.ofMillis(800)))
    .addAction(dedo.createPointerUp(PointerInput.MouseButton.LEFT.asArg()));
driver.perform(List.of(toqueLongo));

    O laboratório usa Pointer Events, então também dá para testar com o mouse, em qualquer navegador.

    import { test, expect } from '@playwright/test';

test('arrasto lento não é swipe', async ({ page }) => {
  await page.goto('/pages/mobile/touch-events.html');
  const pad = page.getByTestId('gesture-pad');
  const box = (await pad.boundingBox())!;

  await page.mouse.move(box.x + 40, box.y + 60);
  await page.mouse.down();
  await page.mouse.move(box.x + 200, box.y + 60, { steps: 30 });
  await page.waitForTimeout(800); // devagar: velocidade abaixo do limite
  await page.mouse.up();

  await expect(page.getByTestId('gesture-last')).toHaveText('arrasto');
  await expect(page.getByTestId('gesture-pointer')).toHaveText('mouse');
});

    Informações para Testes

    Cenários de Teste:

    • Testar eventos touchstart, touchmove, touchend
    • Validar gestos de swipe em diferentes direções
    • Testar long press e double tap
    • Validar área de toque mínima (44x44px recomendado)
    • Testar scroll e drag em elementos móveis
    • Validar prevenção de zoom acidental
    • Testar multi-touch (pinch, zoom)

    Elementos identificáveis:

    • data-testid="touch-area" - Área de teste de toque
    • data-testid="touch-log" - Log de eventos touch
    • data-testid="btn-tap" - Botão de tap
    • data-testid="btn-long-press" - Botão de long press
    • data-testid="btn-double-tap" - Botão de double tap
    • data-testid="swipe-area" - Área de swipe
    • data-testid="swipe-direction" - Direção do swipe

# Appium + Ruby - Testar touch events
caps = {
  platformName: 'Android',
  deviceName: 'Android Emulator',
  browserName: 'Chrome',
  automationName: 'UiAutomator2'
}
driver = Appium::Driver.new({ caps: caps }).start_driver

driver.get('http://localhost:8080/pages/mobile/touch-events.html')

# Testar tap
touch_area = driver.find_element(:css, '[data-testid="touch-area"]')
Appium::TouchAction.new.tap(element: touch_area).perform

touch_log = driver.find_element(:css, '[data-testid="touch-log"]')
expect(touch_log.text).to include('touchstart')

# Testar swipe
swipe_area = driver.find_element(:css, '[data-testid="swipe-area"]')
Appium::TouchAction.new
  .press(element: swipe_area, x: 100, y: 50)
  .move_to(element: swipe_area, x: 50, y: 50)
  .release
  .perform

swipe_direction = driver.find_element(:css, '[data-testid="swipe-direction"]')
expect(swipe_direction.text).to include('left')
