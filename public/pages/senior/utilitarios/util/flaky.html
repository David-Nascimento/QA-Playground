Informações para Testes

Características de Testes Flaky:

  • Elementos que aparecem/disparecem aleatoriamente
  • Delays variáveis que causam condições de corrida
  • Estados que mudam antes do teste verificar
  • Dependências de timing que não são estáveis
  • Elementos que podem ou não aparecer baseado em probabilidade

Estratégias para Lidar com Flaky Tests:

  • Use waits explícitos e robustos
  • Implemente retry logic quando apropriado
  • Evite depender de timing fixo
  • Use seletores estáveis (data-testid)
  • Valide estados, não apenas presença de elementos
  • Isolate testes para evitar dependências

Exemplos de Teste Automatizado:


// Cypress - Aguardar elemento flaky com retry
cy.get('[data-testid="btn-trigger-flaky"]').click()
cy.get('[data-testid="flaky-element"]', { timeout: 5000 }).should('be.visible').then(() => {
  cy.get('[data-testid="flaky-result"]').should('contain', 'detectado')
})

// Usar retry para elemento que pode não aparecer
cy.get('[data-testid="btn-trigger-flaky"]').click()
cy.get('[data-testid="flaky-element"]', { timeout: 10000 }).should('exist')
                

// Playwright - Wait robusto para elemento flaky
await page.getByTestId('btn-trigger-flaky').click()
await page.getByTestId('flaky-element').waitFor({ state: 'visible', timeout: 10000 }).catch(() => {
  // Elemento pode não aparecer - comportamento flaky
})

// Aguardar com retry
try {
  await page.getByTestId('flaky-element').waitFor({ state: 'visible', timeout: 10000 })
} catch (e) {
  // Elemento não apareceu - comportamento flaky esperado
}
                

// Selenium (Java) - Wait com timeout maior
driver.findElement(By.cssSelector("[data-testid='btn-trigger-flaky']")).click();
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
try {
  wait.until(ExpectedConditions.visibilityOfElementLocated(
    By.cssSelector("[data-testid='flaky-element']")
  ));
} catch (TimeoutException e) {
  // Elemento não apareceu - comportamento flaky
}
                

# Capybara (Ruby) - Aguardar elemento flaky
click_button '[data-testid="btn-trigger-flaky"]'
begin
  expect(page).to have_css('[data-testid="flaky-element"]', visible: true, wait: 10)
rescue Capybara::ElementNotFound
  # Elemento não apareceu - comportamento flaky
end
