Informações para Testes

Cenários de Teste:

  • Testar busca de IP público via API
  • Validar formato do endereço IP (IPv4/IPv6)
  • Testar tratamento de erros de rede
  • Validar informações de geolocalização
  • Testar funcionalidade de copiar IP
  • Validar estados de carregamento

Exemplos de Teste Automatizado:


// Cypress - Buscar e validar IP
cy.get('[data-testid="btn-fetch-ip"]').click()
cy.get('[data-testid="ip-address"]', { timeout: 2000 }).should('be.visible')
cy.get('[data-testid="ip-address"]').should('match', /^\d+\.\d+\.\d+\.\d+$/)
cy.get('[data-testid="btn-copy-ip"]').click()
                

// Playwright - Validar IP
await page.getByTestId('btn-fetch-ip').click()
await expect(page.getByTestId('ip-address')).toBeVisible()
const ip = await page.getByTestId('ip-address').textContent()
expect(ip).toMatch(/^\d+\.\d+\.\d+\.\d+$/)

// Copiar IP
await page.getByTestId('btn-copy-ip').click()
                

// Selenium (Java) - Validar formato de IP
driver.findElement(By.cssSelector("[data-testid='btn-fetch-ip']")).click();
Thread.sleep(2000);
WebElement ipElement = driver.findElement(By.cssSelector("[data-testid='ip-address']"));
String ip = ipElement.getText();
assert ip.matches("\\d+\\.\\d+\\.\\d+\\.\\d+");
                

# Capybara (Ruby) - Validar IP
click_button '[data-testid="btn-fetch-ip"]'
expect(page).to have_css('[data-testid="ip-address"]', text: /^\d+\.\d+\.\d+\.\d+$/, wait: 2)
click_button '[data-testid="btn-copy-ip"]'
