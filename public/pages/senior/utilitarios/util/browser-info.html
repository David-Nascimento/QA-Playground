Informações para Testes

Cenários de Teste:

  • Validar informações do user agent
  • Verificar resolução da tela e viewport
  • Testar detecção de recursos do navegador
  • Validar timezone e idioma
  • Testar detecção de status online/offline
  • Validar suporte a cookies e storage

Exemplos de Teste Automatizado:


// Cypress - Validar informações do navegador
cy.get('[data-testid="user-agent"]').should('not.be.empty')
cy.get('[data-testid="platform"]').should('contain', 'Win')
cy.get('[data-testid="screen-resolution"]').should('match', /\d+x\d+/)
cy.get('[data-testid="btn-refresh"]').click()
cy.get('[data-testid="viewport"]').should('not.be.empty')
                

// Playwright - Obter informações
const userAgent = await page.getByTestId('user-agent').textContent()
const platform = await page.getByTestId('platform').textContent()
expect(userAgent).toBeTruthy()
expect(platform).toBeTruthy()

// Atualizar informações
await page.getByTestId('btn-refresh').click()
await expect(page.getByTestId('viewport')).not.toBeEmpty()
                

// Selenium (Java) - Validar informações
WebElement userAgent = driver.findElement(By.cssSelector("[data-testid='user-agent']"));
assert !userAgent.getText().isEmpty();
WebElement resolution = driver.findElement(By.cssSelector("[data-testid='screen-resolution']"));
assert resolution.getText().matches("\\d+x\\d+");
driver.findElement(By.cssSelector("[data-testid='btn-refresh']")).click();
                

# Capybara (Ruby) - Validar informações
expect(page).to have_css('[data-testid="user-agent"]', text: /.+/)
expect(page).to have_css('[data-testid="screen-resolution"]', text: /\d+x\d+/)
click_button '[data-testid="btn-refresh"]'

  • data-testid="browser-info" - Container principal
  • data-testid="user-agent" - User agent string
  • data-testid="platform" - Plataforma do sistema
  • data-testid="screen-resolution" - Resolução da tela
  • data-testid="btn-refresh" - Botão de atualizar
