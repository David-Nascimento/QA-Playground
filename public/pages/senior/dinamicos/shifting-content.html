Shifting Content

Valide mudanças de layout e conteúdo inesperadas. Esta página demonstra elementos que mudam de posição, simulando problemas de layout que podem causar testes flaky.

Conteúdo que se Move

Clique no botão abaixo para mover o conteúdo. Teste a validação de elementos que mudam de posição.

Conteúdo que se move

Conteúdo na posição inicial.

Informações para Testes

Cenários de Teste:

  • Testar elementos que mudam de posição
  • Validar posição de elementos após movimento
  • Testar cliques em elementos que se movem
  • Validar que seletores funcionam após movimento
  • Testar screenshots comparativos
  • Validar layout após mudanças de posição

Exemplos de Teste Automatizado:


// Cypress - Validar posição de elemento
cy.get('[data-testid="shift-content"]').should('have.css', 'left', '0px')
cy.get('[data-testid="btn-mover-conteudo"]').click()
cy.get('[data-testid="shift-content"]').should('not.have.css', 'left', '0px')

// Validar posição específica
cy.get('[data-testid="shift-content"]').then(($el) => {
  const left = $el.css('left')
  expect(left).to.not.equal('0px')
})
                

// Playwright - Validar movimento
const element = page.getByTestId('shift-content')
const initialLeft = await element.evaluate(el => el.offsetLeft)
await page.getByTestId('btn-mover-conteudo').click()
await page.waitForTimeout(600) // Aguardar transição
const newLeft = await element.evaluate(el => el.offsetLeft)
expect(newLeft).not.toBe(initialLeft)
                

// Selenium (Java) - Validar movimento
WebElement content = driver.findElement(By.cssSelector("[data-testid='shift-content']"));
JavascriptExecutor js = (JavascriptExecutor) driver;
Long initialLeft = (Long) js.executeScript("return arguments[0].offsetLeft;", content);
driver.findElement(By.cssSelector("[data-testid='btn-mover-conteudo']")).click();
Thread.sleep(600);
Long newLeft = (Long) js.executeScript("return arguments[0].offsetLeft;", content);
assert !newLeft.equals(initialLeft);
                

# Capybara (Ruby) - Validar movimento
element = find('[data-testid="shift-content"]')
initial_left = page.evaluate_script('arguments[0].offsetLeft', element.native)
click_button '[data-testid="btn-mover-conteudo"]'
sleep 0.6
new_left = page.evaluate_script('arguments[0].offsetLeft', element.native)
expect(new_left).not_to eq(initial_left)
