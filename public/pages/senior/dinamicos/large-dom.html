Informações para Testes

Desafios de Automação:

  • DOMs com muitos elementos (1000+)
  • Profundidade de aninhamento elevada (5+ níveis)
  • Performance de seletores em DOMs grandes
  • Seleção de elementos em níveis profundos
  • Validação de elementos específicos em meio a muitos outros
  • Testes de performance e tempo de execução

Estratégias Recomendadas:

  • Use seletores específicos e diretos quando possível
  • Prefira data-testid para seleção rápida
  • Evite seletores muito genéricos (ex: div div div)
  • Use XPath ou CSS específicos para elementos profundos
  • Considere esperar elementos aparecerem antes de interagir
  • Monitore performance de testes em DOMs grandes

Exemplos de Teste Automatizado:


// Cypress - Encontrar elemento profundo
cy.get('[data-testid="large-dom"]')
  .find('[data-testid="elemento-profundo-5"]')
  .should('be.visible')
  .click()

// Contar elementos
cy.get('[data-testid="large-dom"]').find('li').should('have.length.greaterThan', 100)

// Clicar em botão e validar resultado
cy.get('[data-testid="btn-encontrar-profundo"]').click()
cy.get('[data-testid="dom-result"]').should('contain', 'Elemento profundo encontrado')

// Contar elementos via botão
cy.get('[data-testid="btn-contar-elementos"]').click()
cy.get('[data-testid="dom-result"]').should('contain', 'Contagem de Elementos')
                

// Playwright - Seleção eficiente
const deepElement = page.getByTestId('large-dom').getByTestId('elemento-profundo-5')
await expect(deepElement).toBeVisible()
await deepElement.click()

// Contar elementos
const liCount = await page.getByTestId('large-dom').locator('li').count()
expect(liCount).toBeGreaterThan(100)

// Clicar em botão e validar resultado
await page.getByTestId('btn-encontrar-profundo').click()
await expect(page.getByTestId('dom-result')).toContainText('Elemento profundo encontrado')

// Contar elementos via botão
await page.getByTestId('btn-contar-elementos').click()
await expect(page.getByTestId('dom-result')).toContainText('Contagem de Elementos')
                

// Selenium Java - XPath para elementos profundos
WebElement deep = driver.findElement(By.xpath(
  "//div[@data-testid='large-dom']//li[@data-testid='elemento-profundo-5']"
));
assert deep.isDisplayed();
deep.click();

// Contar elementos
List<WebElement> liElements = driver.findElements(
  By.cssSelector("[data-testid='large-dom'] li")
);
assert liElements.size() > 100;

// Clicar em botão e validar resultado
driver.findElement(By.cssSelector("[data-testid='btn-encontrar-profundo']")).click();
WebElement result = driver.findElement(By.cssSelector("[data-testid='dom-result']"));
assert result.getText().contains("Elemento profundo encontrado");

// Contar elementos via botão
driver.findElement(By.cssSelector("[data-testid='btn-contar-elementos']")).click();
assert result.getText().contains("Contagem de Elementos");
                

# Capybara (Ruby) - Encontrar elemento profundo
within('[data-testid="large-dom"]') do
  find('[data-testid="elemento-profundo-5"]').click
end

# Contar elementos
expect(page).to have_css('[data-testid="large-dom"] li', minimum: 100)

# Clicar em botão e validar resultado
find('[data-testid="btn-encontrar-profundo"]').click
expect(find('[data-testid="dom-result"]')).to have_content('Elemento profundo encontrado')

# Contar elementos via botão
find('[data-testid="btn-contar-elementos"]').click
expect(find('[data-testid="dom-result"]')).to have_content('Contagem de Elementos')

Contar elementos
    Click Element    css:[data-testid="btn-contar-elementos"]

    Should Be True    ${count} > 100

Clicar em elemento profundo
    Click Element    css:[data-testid="large-dom"] css:[data-testid="elemento-profundo-5"]
    Element Should Be Visible    css:[data-testid="elemento-profundo-5"]

Elementos identificáveis:

  • data-testid="large-dom" - Container do DOM grande
  • data-testid="btn-encontrar-profundo" - Botão encontrar elemento profundo
  • data-testid="btn-contar-elementos" - Botão contar elementos
  • data-testid="elemento-profundo-{nivel}" - Elementos em diferentes níveis
  • data-testid="dom-result" - Área de resultados
