JavaScript Error

Simule e capture erros de JavaScript na página. Esta página permite testar a detecção de erros JavaScript, validação de tratamento de erros e integração com ferramentas de automação que capturam erros do console.

Informações para Testes

Cenários de Teste:

  • Capturar erros JavaScript no console
  • Validar que erros são detectados corretamente
  • Testar diferentes tipos de erros (ReferenceError, TypeError, SyntaxError)
  • Validar mensagens de erro exibidas
  • Testar tratamento de erros não capturados
  • Validar integração com ferramentas de automação

Exemplos de Teste Automatizado:


// Cypress - Capturar erros JavaScript
cy.window().then((win) => {
  win.addEventListener('error', (e) => {
    expect(e.message).to.include('ReferenceError')
  })
})
cy.get('[data-testid="btn-error-reference"]').click()

// Capturar erro de sintaxe
cy.get('[data-testid="btn-error-syntax"]').click()
cy.window().its('console').then((console) => {
  cy.stub(console, 'error').as('consoleError')
})
                

// Playwright - Capturar erros
page.on('pageerror', error => {
  console.log('Erro capturado:', error.message)
})
await page.click('[data-testid="btn-error-reference"]')

// Capturar erro de sintaxe
await page.click('[data-testid="btn-error-syntax"]')
const errors = await page.evaluate(() => window.errors || [])
expect(errors.length).toBeGreaterThan(0)
                

// Selenium (Java) - Verificar logs de console
LogEntries logs = driver.manage().logs().get(LogType.BROWSER);
for (LogEntry entry : logs) {
  if (entry.getLevel() == Level.SEVERE) {
    System.out.println("Erro: " + entry.getMessage());
  }
}

// Clicar em botão que gera erro
driver.findElement(By.cssSelector("[data-testid='btn-error-reference']")).click();
                

# Capybara (Ruby) - Capturar erros JavaScript
page.driver.browser.logs.get(:browser).each do |log|
  puts "Erro: #{log.message}" if log.level == 'SEVERE'
end

# Clicar em botão que gera erro
find('[data-testid="btn-error-reference"]').click

Capturar erros JavaScript
    ${logs}=    Get Browser Logs
    FOR    ${log}    IN    @{logs}
        Log    ${log}[message]
    END
    Click Element    css:[data-testid="btn-error-reference"]

Elementos identificáveis:

  • data-testid="btn-error-reference" - Botão erro de referência
  • data-testid="btn-error-type" - Botão erro de tipo
  • data-testid="btn-error-syntax" - Botão erro de sintaxe
  • data-testid="btn-error-custom" - Botão erro customizado
  • data-testid="error-status" - Status dos erros
