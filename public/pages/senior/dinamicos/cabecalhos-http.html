Informações para Testes

Cenários de Teste:

  • Visualizar cabeçalhos HTTP da requisição
  • Testar envio de headers personalizados
  • Validar headers de autenticação (Authorization)
  • Testar headers de conteúdo (Content-Type)
  • Validar headers de cache (Cache-Control)
  • Testar interceptação de headers em automação

Exemplos de Teste Automatizado:


// Cypress - Interceptar e validar headers
cy.intercept('GET', '**/api/**', (req) => {
  req.headers['Authorization'] = 'Bearer token123'
  req.headers['Content-Type'] = 'application/json'
}).as('apiCall')
cy.visit('/page')
cy.wait('@apiCall').then((interception) => {
  expect(interception.request.headers['Authorization']).to.include('Bearer')
})
                

// Playwright - Adicionar headers
await page.setExtraHTTPHeaders({
  'Authorization': 'Bearer token123',
  'X-Custom-Header': 'custom-value'
})
await page.goto('/page')
                

// Selenium (Java) - Adicionar headers via Chrome DevTools
ChromeOptions options = new ChromeOptions();
options.addArguments("--user-agent=CustomAgent");
Map<String, String> headers = new HashMap<>();
headers.put("Authorization", "Bearer token123");
options.setExperimentalOption("prefs", headers);
                

# Capybara (Ruby) - Adicionar headers
page.driver.add_header('Authorization', 'Bearer token123')
page.driver.add_header('X-Custom-Header', 'custom-value')
visit '/page'
