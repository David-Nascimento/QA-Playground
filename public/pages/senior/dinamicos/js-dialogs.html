Informações para Testes

Cenários de Teste:

  • Testar automação de alert()
  • Testar automação de confirm() (OK e Cancel)
  • Testar automação de prompt() (entrada de texto)
  • Validar que diálogos são detectados
  • Testar aceitar/recusar diálogos
  • Validar mensagens exibidas nos diálogos

Exemplos de Teste Automatizado:


// Cypress - Interagir com alert
cy.window().then((win) => {
  cy.stub(win, 'alert').as('alertStub')
})
cy.get('[data-testid="btn-alert"]').click()
cy.get('@alertStub').should('have.been.calledWith', 'Este é um alert!')

// Interagir com confirm
cy.window().then((win) => {
  cy.stub(win, 'confirm').returns(true).as('confirmStub')
})
cy.get('[data-testid="btn-confirm"]').click()
cy.get('@confirmStub').should('have.been.called')
                

// Playwright - Aceitar diálogos
page.on('dialog', async dialog => {
  console.log('Diálogo:', dialog.message())
  await dialog.accept()
})
await page.getByTestId('btn-alert').click()

// Aceitar confirm
page.on('dialog', async dialog => {
  await dialog.accept()
})
await page.getByTestId('btn-confirm').click()
                

// Selenium (Java) - Aceitar alert
Alert alert = driver.switchTo().alert();
String message = alert.getText();
alert.accept();

// Aceitar confirm
driver.findElement(By.cssSelector("[data-testid='btn-confirm']")).click();
Alert confirm = driver.switchTo().alert();
confirm.accept();
                

# Capybara (Ruby) - Aceitar diálogo
accept_alert do
  click_button '[data-testid="btn-alert"]'
end

# Aceitar confirm
accept_confirm do
  click_button '[data-testid="btn-confirm"]'
end

Aceitar confirm
    Click Button    css:[data-testid="btn-confirm"]
    Handle Alert    ACCEPT

Elementos identificáveis:

  • data-testid="btn-alert" - Botão disparar alert
  • data-testid="btn-confirm" - Botão disparar confirm
  • data-testid="btn-prompt" - Botão disparar prompt
  • data-testid="dialog-result" - Resultado dos diálogos
