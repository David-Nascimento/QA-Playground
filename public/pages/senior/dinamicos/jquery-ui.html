Informações para Testes

Cenários de Teste:

  • Testar drag and drop com jQuery UI
  • Validar que elemento foi arrastado corretamente
  • Testar drop em zona de soltura
  • Validar eventos de jQuery UI
  • Testar interação com widgets jQuery
  • Validar que jQuery UI está carregado

Exemplos de Teste Automatizado:


// Cypress - Drag and drop jQuery UI
cy.get('[data-testid="draggable-jquery"]').trigger('mousedown', { which: 1 })
cy.get('[data-testid="droppable-jquery"]').trigger('mousemove').trigger('mouseup')
cy.get('[data-testid="droppable-jquery"]').should('contain', 'Soltou')

// Validar que jQuery UI está carregado
cy.window().its('jQuery.ui').should('exist')
                

// Playwright - Drag and drop
await page.getByTestId('draggable-jquery').dragTo(page.getByTestId('droppable-jquery'))
await expect(page.getByTestId('droppable-jquery')).toContainText('Soltou')

// Validar jQuery UI
const jqueryUI = await page.evaluate(() => window.jQuery && window.jQuery.ui)
expect(jqueryUI).toBeTruthy()
                

// Selenium (Java) - Drag and drop jQuery UI
WebElement source = driver.findElement(By.cssSelector("[data-testid='draggable-jquery']"));
WebElement target = driver.findElement(By.cssSelector("[data-testid='droppable-jquery']"));
Actions actions = new Actions(driver);
actions.dragAndDrop(source, target).perform();
                

# Capybara (Ruby) - Drag and drop
source = find('[data-testid="draggable-jquery"]')
target = find('[data-testid="droppable-jquery"]')
source.drag_to(target)
expect(page).to have_content('Soltou', within: '[data-testid="droppable-jquery"]')
