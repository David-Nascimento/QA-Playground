Informações para Testes

Desafios de Automação:

  • Elementos com classes dinâmicas que mudam a cada interação
  • IDs podem ser alterados dinamicamente
  • Conteúdo dos elementos pode variar
  • Múltiplos elementos similares que exigem seleção precisa
  • Validar estado após ações dinâmicas

Estratégias Recomendadas:

  • Use data-testid para seleção estável
  • Prefira seletores por conteúdo quando apropriado
  • Evite depender de classes CSS que mudam
  • Valide estados, não apenas classes
  • Use waits explícitos para elementos dinâmicos

Exemplos de Teste Automatizado:


// Cypress - Usar data-testid (recomendado)
cy.get('[data-testid="btn-a"]').click()
cy.get('[data-testid="resultado-acao"]').should('contain', 'Botão A')
cy.get('[data-testid="box1"]').should('be.visible')

// Testar botão B
cy.get('[data-testid="btn-b"]').click()
cy.get('[data-testid="resultado-acao"]').should('contain', 'Botão B')
                

// Playwright - Seleção estável
await page.getByTestId('btn-b').click()
await expect(page.getByTestId('resultado-acao')).toContainText('Botão B')

// Testar botão A
await page.getByTestId('btn-a').click()
await expect(page.getByTestId('resultado-acao')).toContainText('Botão A')
                

// Selenium (Java) - Usar data-testid
driver.findElement(By.cssSelector("[data-testid='btn-a']")).click();
WebElement resultado = driver.findElement(By.cssSelector("[data-testid='resultado-acao']"));
assert resultado.getText().contains("Botão A");

// Testar botão B
driver.findElement(By.cssSelector("[data-testid='btn-b']")).click();
assert resultado.getText().contains("Botão B");
                

# Capybara (Ruby) - Seleção estável
click_button '[data-testid="btn-a"]'
expect(page).to have_content('Botão A', within: '[data-testid="resultado-acao"]')

# Testar botão B
click_button '[data-testid="btn-b"]'
expect(page).to have_content('Botão B', within: '[data-testid="resultado-acao"]')
