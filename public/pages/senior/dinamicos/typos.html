Informações para Testes

Cenários de Teste:

  • Testar digitação correta e validação de sucesso
  • Validar detecção de erros de digitação
  • Testar diferentes variações e typos comuns
  • Validar mensagens de erro exibidas
  • Testar campo vazio e validação
  • Validar feedback visual de sucesso/erro

Exemplos de Teste Automatizado:


// Cypress - Testar typos
cy.get('[data-testid="typo-input"]').type('QA Playground')
cy.get('[data-testid="btn-validar-typo"]').click()
cy.get('[data-testid="typo-feedback"]').should('contain', 'Correto')

// Testar erro de digitação
cy.get('[data-testid="typo-input"]').clear().type('QA Playgroun')
cy.get('[data-testid="btn-validar-typo"]').click()
cy.get('[data-testid="typo-feedback"]').should('contain', 'erro')
                

// Playwright - Testar typos
await page.getByTestId('typo-input').fill('QA Playground')
await page.getByTestId('btn-validar-typo').click()
await expect(page.getByTestId('typo-feedback')).toContainText('Correto')

// Testar erro
await page.getByTestId('typo-input').fill('QA Playgroun')
await page.getByTestId('btn-validar-typo').click()
await expect(page.getByTestId('typo-feedback')).toContainText('erro')
                

// Selenium (Java) - Validar typos
driver.findElement(By.cssSelector("[data-testid='typo-input']")).sendKeys("QA Playground");
driver.findElement(By.cssSelector("[data-testid='btn-validar-typo']")).click();
WebElement feedback = driver.findElement(By.cssSelector("[data-testid='typo-feedback']"));
assert feedback.getText().contains("Correto");
                

# Capybara (Ruby) - Testar typos
fill_in '[data-testid="typo-input"]', with: 'QA Playground'
click_button '[data-testid="btn-validar-typo"]'
expect(page).to have_content('Correto', within: '[data-testid="typo-feedback"]')

  • data-testid="btn-validar-typo" - Botão validar
  • data-testid="btn-limpar-typo" - Botão limpar
  • data-testid="typo-feedback" - Área de feedback
