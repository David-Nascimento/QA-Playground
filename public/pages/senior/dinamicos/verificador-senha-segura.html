Verificador de Senha Segura

Teste a força de senhas e dicas de segurança. Esta página permite testar a validação de senhas, verificação de critérios de segurança e feedback em tempo real sobre a força da senha.

Verificar Força da Senha

Digite uma senha no campo abaixo para verificar sua força. A senha será avaliada em tempo real.

Critérios de Segurança:

  • Pelo menos 8 caracteres
  • Uma letra maiúscula
  • Um número
  • Um caractere especial (!@#$%^&*)

Digite uma senha para verificar.

Informações para Testes

Cenários de Teste:

  • Testar senha fraca (não atende critérios)
  • Testar senha média (atende alguns critérios)
  • Testar senha forte (atende todos os critérios)
  • Validar feedback em tempo real
  • Testar validação de cada critério individualmente
  • Validar barra de força da senha

Exemplos de Teste Automatizado:


// Cypress - Testar senha fraca
cy.get('[data-testid="input-senha-verificar"]').type('senha')
cy.get('[data-testid="senha-result"]').should('contain', 'fraca')
cy.get('[data-testid="criterio-length"]').should('have.class', 'incomplete')

// Testar senha forte
cy.get('[data-testid="input-senha-verificar"]').clear().type('Senha123!')
cy.get('[data-testid="senha-result"]').should('contain', 'forte')
cy.get('[data-testid="criterio-length"]').should('have.class', 'complete')
                

// Playwright - Validar senha
await page.getByTestId('input-senha-verificar').fill('Senha123!')
await expect(page.getByTestId('senha-result')).toContainText('forte')
await expect(page.getByTestId('criterio-length')).toHaveClass(/complete/)

// Testar senha fraca
await page.getByTestId('input-senha-verificar').fill('senha')
await expect(page.getByTestId('senha-result')).toContainText('fraca')
                

// Selenium (Java) - Validar senha forte
driver.findElement(By.cssSelector("[data-testid='input-senha-verificar']")).sendKeys("Senha123!");
WebElement result = driver.findElement(By.cssSelector("[data-testid='senha-result']"));
assert result.getText().contains("forte");
WebElement criterio = driver.findElement(By.cssSelector("[data-testid='criterio-length']"));
assert criterio.getAttribute("class").contains("complete");
                

# Capybara (Ruby) - Validar senha
fill_in '[data-testid="input-senha-verificar"]', with: 'Senha123!'
expect(page).to have_content('forte', within: '[data-testid="senha-result"]')
expect(page).to have_css('[data-testid="criterio-length"].criterio-complete')
