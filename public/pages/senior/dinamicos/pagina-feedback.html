Informações para Testes

Cenários de Teste:

  • Selecionar avaliação (estrelas)
  • Preencher campo de feedback
  • Testar envio de feedback
  • Validar que avaliação é obrigatória
  • Testar limpeza de formulário
  • Validar mensagem de sucesso após envio

Exemplos de Teste Automatizado:


// Cypress - Enviar feedback
cy.get('[data-testid="rating-5"]').click()
cy.get('[data-testid="rating-value"]').should('have.value', '5')
cy.get('[data-testid="textarea-feedback"]').type('Ótimo projeto!')
cy.get('[data-testid="btn-enviar-feedback"]').click()
cy.get('[data-testid="feedback-result"]').should('contain', 'enviado')
                

// Playwright - Enviar feedback
await page.getByTestId('rating-4').click()
await page.getByTestId('textarea-feedback').fill('Feedback de teste')
await page.getByTestId('btn-enviar-feedback').click()
await expect(page.getByTestId('feedback-result')).toContainText('enviado')
                

// Selenium (Java) - Enviar feedback
driver.findElement(By.cssSelector("[data-testid='rating-5']")).click();
driver.findElement(By.cssSelector("[data-testid='textarea-feedback']")).sendKeys("Ótimo projeto!");
driver.findElement(By.cssSelector("[data-testid='btn-enviar-feedback']")).click();
WebElement result = driver.findElement(By.cssSelector("[data-testid='feedback-result']"));
assert result.getText().contains("enviado");
                

# Capybara (Ruby) - Enviar feedback
find('[data-testid="rating-5"]').click
fill_in '[data-testid="textarea-feedback"]', with: 'Ótimo projeto!'
click_button '[data-testid="btn-enviar-feedback"]'
expect(page).to have_content('enviado', within: '[data-testid="feedback-result"]')

Elementos identificáveis:

  • data-testid="form-feedback" - Formulário de feedback
  • data-testid="rating-{1-5}" - Botões de avaliação
  • data-testid="rating-value" - Valor da avaliação
  • data-testid="textarea-feedback" - Campo de feedback
  • data-testid="btn-enviar-feedback" - Botão enviar
  • data-testid="feedback-result" - Resultado do envio
