Informações para Testes

Cenários de Teste:

  • Testar carregamento de conteúdo após delay
  • Validar estado de "carregando" antes do conteúdo aparecer
  • Testar waits explícitos para elementos dinâmicos
  • Validar que conteúdo aparece após carregamento
  • Testar múltiplos carregamentos
  • Validar tratamento de timeouts

Exemplos de Teste Automatizado:


// Cypress - Aguardar elemento dinâmico
cy.get('[data-testid="btn-carregar-conteudo"]').click()
cy.get('[data-testid="conteudo-carregado"]', { timeout: 5000 }).should('be.visible')
cy.get('[data-testid="conteudo-carregado"]').should('contain', 'Carregado')

// Aguardar texto específico
cy.get('[data-testid="btn-carregar-conteudo"]').click()
cy.contains('[data-testid="conteudo-carregado"]', 'Carregado', { timeout: 5000 })
                

// Playwright - Wait for element
await page.getByTestId('btn-carregar-conteudo').click()
await page.getByTestId('conteudo-carregado').waitFor({ state: 'visible' })
await expect(page.getByTestId('conteudo-carregado')).toContainText('Carregado')

// Aguardar texto específico
await page.getByTestId('conteudo-carregado').waitFor({ 
  state: 'visible',
  timeout: 5000 
})
                

// Selenium (Java) - Explicit wait
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(5));
driver.findElement(By.cssSelector("[data-testid='btn-carregar-conteudo']")).click();
WebElement loaded = wait.until(ExpectedConditions.visibilityOfElementLocated(
  By.cssSelector("[data-testid='conteudo-carregado']")
));
assert loaded.getText().contains("Carregado");
                

# Capybara (Ruby) - Aguardar conteúdo carregar
click_button '[data-testid="btn-carregar-conteudo"]'
expect(page).to have_css('[data-testid="conteudo-carregado"]', visible: true, wait: 5)
expect(page).to have_content('Carregado', wait: 5)
