Saiba mais sobre o projeto e sua proposta. Esta página contém informações sobre o QA Playground, seus objetivos e como utilizá-lo para prática de testes.

Sobre o Projeto

O QA Playground é uma plataforma prática para execução de testes manuais e automatizados, validação de interfaces web e simulação de APIs. Este projeto foi criado para fins educacionais e de treinamento, inspirado em iniciativas como o The Internet e outros playgrounds de testes.

Objetivos

  • Fornecer um ambiente controlado para prática de testes
  • Demonstrar diferentes cenários e desafios de automação
  • Facilitar o aprendizado de ferramentas de teste (Cypress, Playwright, Selenium, etc.)
  • Oferecer exemplos práticos de testes automatizados
  • Simular situações reais encontradas em aplicações web

Estrutura do Projeto

  • Nível Júnior: Conceitos básicos, formulários, tabelas e interações simples
  • Nível Pleno: Cenários intermediários, tabelas complexas, arquivos e interações avançadas
  • Nível Sênior: Desafios avançados, DOM complexo, APIs, autenticação e cenários reais

Características

  • Todas as páginas possuem elementos identificáveis (id e data-testid)
  • Documentação completa para cada seção
  • Exemplos de código para diferentes ferramentas de automação
  • Suporte a tema claro/escuro
  • Interface responsiva e acessível

Como Utilizar

Para Testes Manuais:

  • Navegue pelas diferentes seções e níveis
  • Pratique testes em diferentes cenários
  • Use os elementos identificáveis para criar casos de teste
  • Explore as funcionalidades de cada página

Para Testes Automatizados:

  • Use os data-testid para seleção estável de elementos
  • Consulte os exemplos de código fornecidos em cada página
  • Adapte os exemplos para sua ferramenta de automação
  • Pratique diferentes estratégias de seleção e validação
