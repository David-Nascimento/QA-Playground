Informações para Testes

Cenários de Teste:

  • Trocar contexto para dentro do iframe
  • Interagir com elementos dentro do iframe
  • Validar conteúdo dentro do iframe
  • Voltar ao contexto principal após interação
  • Testar múltiplos iframes na mesma página
  • Validar que elementos do iframe não são acessíveis do contexto principal

Exemplos de Teste Automatizado:


// Cypress - Interagir com iframe
cy.get('[data-testid="test-iframe"]')
  .its('0.contentDocument.body')
  .should('not.be.empty')
  .then(cy.wrap)
  .find('[data-testid="input-iframe"]')
  .type('Texto no iframe')
                

// Playwright - Interagir com iframe
const frame = await page.frameLocator('[data-testid="test-iframe"]')
await frame.getByTestId('input-iframe').fill('Texto no iframe')

// Clicar em botão dentro do iframe
await frame.getByTestId('btn-iframe').click()
                

// Selenium (Java) - Interagir com iframe
driver.switchTo().frame(driver.findElement(By.cssSelector("[data-testid='test-iframe']")));
WebElement input = driver.findElement(By.cssSelector("[data-testid='input-iframe']"));
input.sendKeys("Texto no iframe");
driver.switchTo().defaultContent();
                

# Capybara (Ruby) - Interagir com iframe
within_frame('[data-testid="test-iframe"]') do
  fill_in '[data-testid="input-iframe"]', with: 'Texto no iframe'
end
