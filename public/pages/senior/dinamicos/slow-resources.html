Informações para Testes

Cenários de Teste:

  • Testar recursos que carregam rapidamente
  • Testar recursos que carregam lentamente
  • Validar waits explícitos para recursos lentos
  • Testar timeouts e tratamento de erros
  • Validar que conteúdo aparece após delay
  • Testar cancelamento de recursos lentos

Exemplos de Teste Automatizado:


// Cypress - Aguardar recurso lento
cy.get('[data-testid="btn-load-slow"]').click()
cy.get('[data-testid="conteudo-carregado"]', { timeout: 6000 }).should('be.visible')
cy.get('[data-testid="conteudo-carregado"]').should('contain', 'carregado')

// Testar timeout
cy.get('[data-testid="btn-load-very-slow"]').click()
cy.get('[data-testid="conteudo-carregado"]', { timeout: 5000 }).should('not.exist')
                

// Playwright - Aguardar recurso
await page.getByTestId('btn-load-slow').click()
await page.getByTestId('conteudo-carregado').waitFor({ state: 'visible', timeout: 6000 })
await expect(page.getByTestId('conteudo-carregado')).toContainText('carregado')
                

// Selenium (Java) - Wait explícito para recurso lento
driver.findElement(By.cssSelector("[data-testid='btn-load-slow']")).click();
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(6));
wait.until(ExpectedConditions.visibilityOfElementLocated(
  By.cssSelector("[data-testid='conteudo-carregado']")
));
                

# Capybara (Ruby) - Aguardar recurso lento
click_button '[data-testid="btn-load-slow"]'
expect(page).to have_css('[data-testid="conteudo-carregado"]', visible: true, wait: 6)
