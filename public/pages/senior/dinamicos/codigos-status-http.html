Códigos de Status HTTP

Teste respostas e fluxos para diferentes códigos HTTP. Esta página permite testar a validação de códigos de status HTTP, tratamento de erros e simulação de diferentes respostas de servidor.

Simular Códigos de Status

Selecione um código de status HTTP para simular uma resposta do servidor.

Selecione um código e clique em "Simular Resposta".

Informações para Testes

Cenários de Teste:

  • Testar códigos de sucesso (2xx)
  • Testar códigos de redirecionamento (3xx)
  • Testar códigos de erro do cliente (4xx)
  • Testar códigos de erro do servidor (5xx)
  • Validar tratamento de erros em automação
  • Testar interceptação de status codes

Exemplos de Teste Automatizado:


// Cypress - Interceptar e validar status code
cy.intercept('GET', '**/api/**', { statusCode: 404, body: { error: 'Not found' } }).as('notFound')
cy.visit('/page')
cy.wait('@notFound').then((interception) => {
  expect(interception.response.statusCode).to.equal(404)
})

// Testar diferentes status codes
cy.intercept('GET', '**/api/**', { statusCode: 500 }).as('serverError')
cy.wait('@serverError').its('response.statusCode').should('eq', 500)
                

// Playwright - Validar status code
const response = await page.request.get('/api/endpoint')
expect(response.status()).toBe(200)

// Interceptar e mockar status
await page.route('**/api/**', route => {
  route.fulfill({ status: 404, body: JSON.stringify({ error: 'Not found' }) })
})
