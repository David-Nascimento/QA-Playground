Laboratório: por que a média engana

Guia do especialista

Pergunta que este cenário responde: a interface continua útil quando a API demora? Latência alta não é só "esperar mais": muda a ordem em que as respostas chegam, trava botões e confunde o usuário se não houver feedback.

Hipótese de teste

Com 5 requisições de 1 s em série, o tempo total é a soma (~5 s). Em paralelo, é o da mais lenta (~1 s). Se o tempo total em paralelo for perto da soma, as requisições estão sendo enfileiradas sem necessidade.

O que medir

Tempo até feedbackQuanto tempo até aparecer um indicador de carregamento. Ideal: menos de 100 ms após o clique.
Latência por requisiçãoDistribuição (p50, p95), não só a média. Veja o laboratório abaixo.
Tempo totalSérie = soma das latências; paralelo ≈ a maior delas.
Botão durante a esperaFica desabilitado ou aceita cliques duplicados?

Critério de aceite (exemplo)

Com latência de 1000 ms e 5 requisições simultâneas, o tempo total fica abaixo de 1,5 s e as 5 aparecem como concluídas.

Armadilhas comuns

  • As requisições deste cenário são simuladas no navegador com setTimeout: elas não aparecem na aba Network. Para tráfego de rede real, use a API mock (npm run dev:api) com o cenário ?scenario=timeout.
  • Comparar só a média: duas configurações com a mesma média podem ter p95 muito diferentes.
  • Medir uma única execução. Repita pelo menos 3 vezes e compare a mediana.
  • Esquecer o estado intermediário: o teste também deve verificar o que o usuário vê durante a espera.

Automatize com Playwright

O teste fixa os parâmetros, mede de fora (como o usuário) e compara série x paralelo.

import { test, expect } from '@playwright/test';

async function rodar(page, simultaneas: boolean) {
  await page.goto('/pages/tools/nft/performance-api-latency.html');
  await page.fill('#latency-input', '1000');
  await page.fill('#request-count', '5');
  await page.locator('#concurrent-requests').setChecked(simultaneas);

  const inicio = Date.now();
  await page.click('#start-requests');
  await expect(page.locator('#metric-completed')).toHaveText('5', { timeout: 10_000 });
  return Date.now() - inicio;
}

test('requisições simultâneas terminam em ~1 latência, não na soma', async ({ page }) => {
  const serie = await rodar(page, false);
  const paralelo = await rodar(page, true);

  expect(serie).toBeGreaterThan(4500);   // ~5 x 1000 ms
  expect(paralelo).toBeLessThan(1500);   // ~1 x 1000 ms + margem
});

Como Testar Este Cenário

  • Network Tab: Use o DevTools Network para observar as requisições simuladas
  • Performance: Meça o tempo de resposta e compare com a latência configurada
  • Concorrência: Teste com requisições simultâneas para ver comportamento assíncrono
  • Métricas: Anote tempos médios e totais para diferentes configurações de latência
  • Automação: Use ferramentas como Lighthouse ou Performance API para medir métricas
