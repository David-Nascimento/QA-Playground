Guia do especialista

Pergunta que este cenário responde: as imagens atrasam o que importa na tela? Imagens costumam ser o maior peso de uma página e o elemento de LCP mais comum.

Hipótese de teste

Com carregamento preguiçoso, só as imagens perto da área visível são baixadas no início. Neste cenário ele é feito com IntersectionObserver: a imagem começa com um marcador vazio e só recebe o endereço real (picsum.photos) quando entra na tela.

O que medir

LCPSe a maior imagem estiver na primeira dobra, ela define o LCP. Bom: ≤ 2,5 s.
Imagens requisitadas x visíveisCom lazy, as que estão fora da tela não devem ser pedidas antes da rolagem (aba Network, filtro Img).
CLSImagens sem largura e altura empurram o conteúdo ao carregar.
Bytes transferidosAba Network, com cache desabilitado.

Critério de aceite (exemplo)

Com 50 imagens e lazy ativado, menos de 20 são requisitadas antes de rolar, e o CLS da página fica ≤ 0,1. Desafio: com lazy ativado, o contador "Carregadas" sobe antes de rolar e o status vira "Concluído" depois de 1 s fixo. O que os números estão contando de verdade?

Armadilhas comuns

  • Usar lazy na imagem principal (LCP): ela passa a carregar mais tarde. Lazy é para o que está fora da primeira tela.
  • Testar com cache cheio: marque "Disable cache" no DevTools.
  • Esquecer width e height (ou aspect-ratio) e causar deslocamento de layout.

Automatize com Playwright

Conta quantas imagens já receberam o endereço real antes e depois de rolar a página.

import { test, expect } from '@playwright/test';

test('lazy load adia imagens fora da tela', async ({ page }) => {
  await page.goto('/pages/tools/nft/load-multiple-images.html');
  await page.fill('#image-count', '50');
  await page.locator('#lazy-load').check();
  await page.click('#load-images');

  // imagens que já pediram o arquivo real (as demais ainda têm o marcador data:)
  const requisitadas = () =>
    page.$$eval('#images-container img', (imgs) =>
      imgs.filter((i) => (i as HTMLImageElement).src.startsWith('https://')).length
    );

  const antes = await requisitadas();
  expect(antes).toBeLessThan(20);

  await page.locator('#images-container img').last().scrollIntoViewIfNeeded();
  await expect.poll(requisitadas).toBeGreaterThan(antes);
});

Como Testar Este Cenário

  • Network Tab: Use DevTools Network para observar o carregamento de imagens
  • Performance: Meça o tempo total de carregamento e uso de banda
  • Lazy Loading: Compare performance com e sem lazy loading
  • Otimização: Teste diferentes tamanhos de imagem
  • Memória: Monitore o uso de memória durante o carregamento
