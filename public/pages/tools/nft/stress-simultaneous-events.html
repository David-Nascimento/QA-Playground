Como Testar Este Cenário

  • Performance: Observe se a aplicação consegue processar todos os eventos
  • CPU: Monitore o uso de CPU durante o disparo de eventos
  • Throttling: Verifique se há throttling ou debounce implementado
  • Memória: Observe se há vazamentos de memória com muitos eventos
  • Responsividade: Teste se a interface continua responsiva
