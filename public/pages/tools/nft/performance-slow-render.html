Como Testar Este Cenário

  • Performance: Use as ferramentas de desenvolvedor (DevTools) para medir o tempo de renderização
  • Monitoramento: Observe o uso de CPU e memória durante a renderização
  • Métricas: Anote os tempos de renderização para diferentes quantidades de elementos
  • Limites: Teste com diferentes valores para identificar o ponto onde a performance degrada
  • Automação: Use ferramentas como Lighthouse ou Performance API para medir métricas
