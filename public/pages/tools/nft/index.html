Cenários de Testes Não Funcionais (NFT)

Páginas de demonstração com cenários reais para prática de testes não funcionais. Cada cenário simula situações comuns encontradas em aplicações web reais.

Por onde começar

Cada cenário tem um guia do especialista com a hipótese de teste, as métricas, um critério de aceite e um teste Playwright pronto. Para quem está começando, esta ordem funciona bem:

  1. Latência de API: entenda média x percentis no laboratório.
  2. Timeout e retry: veja por que retries sincronizados derrubam servidores.
  3. Tabela com muitos dados: meça o custo do DOM e o que o usuário sente.
  4. Renderização lenta: responsividade (INP) durante trabalho pesado.
  5. Os demais cenários (imagens, estresse e falhas) combinam o que você praticou.
