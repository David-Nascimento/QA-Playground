Desafio 1: Validação de Formulário de Login

Objetivo: Testar o formulário de login com validações de campos obrigatórios, formatos e mensagens de erro.

Regras de Negócio

  • Email: Campo obrigatório, deve ter formato válido (ex: usuario@dominio.com)
  • Senha: Campo obrigatório, mínimo de 6 caracteres
  • Lembrar-me: Campo opcional (checkbox)
  • Validação: Mensagens de erro devem aparecer em tempo real ao sair do campo (blur)
  • Submissão: Formulário só pode ser submetido quando ambos os campos estão válidos
  • Credenciais válidas: Email: teste@qaplayground.com | Senha: senha123

Cenários de Teste

Cenário 1: Login com Sucesso

O que fazer: Preencher email e senha válidos e clicar em "Entrar"

Dados de Teste: Email: teste@qaplayground.com | Senha: senha123

Resultado Esperado: Toast de sucesso aparece, formulário é limpo, botão volta ao estado normal

Cenário 2: Campos Vazios

O que fazer: Clicar em "Entrar" sem preencher nenhum campo

Resultado Esperado: Mensagens de erro aparecem para ambos os campos

Mensagens Esperadas: Email: "Email é obrigatório." | Senha: "Senha é obrigatória."

Cenário 3: Email Vazio

O que fazer: Preencher apenas a senha e clicar em "Entrar"

Resultado Esperado: Erro aparece apenas no campo email

Cenário 4: Senha Vazia

O que fazer: Preencher apenas o email e clicar em "Entrar"

Resultado Esperado: Erro aparece apenas no campo senha

Cenário 5: Email com Formato Inválido

O que fazer: Digitar email inválido (ex: email-sem-arroba) e sair do campo

Resultado Esperado: Mensagem "Formato de email inválido." aparece

Exemplos de emails inválidos: email-sem-arroba.com, @dominio.com, usuario@

Cenário 6: Senha Curta

O que fazer: Digitar senha com menos de 6 caracteres (ex: 12345) e sair do campo

Resultado Esperado: Mensagem "Senha deve ter no mínimo 6 caracteres." aparece

Como Procurar Elementos

  • Formulário: data-testid="form-login" ou id="login-form"
  • Campo Email: id="email" ou data-testid="input-email"
  • Campo Senha: id="password" ou data-testid="input-senha"
  • Botão Entrar: id="btn-login" ou data-testid="btn-login"
  • Mensagem Erro Email: id="email-error"
  • Mensagem Erro Senha: id="password-error"

Instruções Passo a Passo

  1. Acesse a página Formulário de Login
  2. Clique em "Entrar" sem preencher nada → Verifique se aparecem mensagens de erro
  3. Preencha apenas a senha → Clique em "Entrar" → Verifique se aparece erro no email
  4. Preencha apenas o email → Clique em "Entrar" → Verifique se aparece erro na senha
  5. Digite email-invalido no campo email → Pressione Tab → Verifique se aparece erro
  6. Digite 12345 no campo senha → Pressione Tab → Verifique se aparece erro
  7. Corrija o email para teste@qaplayground.com → Verifique se o erro desaparece
  8. Preencha email: teste@qaplayground.com e senha: senha123
  9. Clique em "Entrar" → Observe que o botão mostra "Autenticando..." e fica desabilitado
  10. Aguarde ~1.5 segundos → Verifique se aparece toast de sucesso

Desafio 2: Validação de Dados em Tabela

Objetivo: Validar dados exibidos em uma tabela dinâmica, verificar consistência e formato das informações.

Regras de Negócio

  • Estrutura: Tabela deve ter cabeçalhos (th) e linhas de dados (tbody tr)
  • Quantidade: Tabela deve conter pelo menos 5 linhas de dados
  • Colunas: Devem existir colunas para: Nome, Email, Idade, Status
  • Formato Email: Todos os emails devem ter formato válido (usuario@dominio.com)
  • Idade: Deve ser um número inteiro positivo entre 18 e 100
  • Status: Deve conter apenas valores: "Ativo", "Inativo" ou "Pendente"
  • Integridade: Não deve haver linhas duplicadas (mesmo email)
  • Completude: Todas as células devem estar preenchidas (sem valores vazios)

Cenários de Teste

Cenário 1: Verificar Estrutura da Tabela

O que fazer: Inspecionar a tabela e verificar se existe e está visível

Resultado Esperado: Tabela existe, tem cabeçalhos (Nome, Email, Idade, Status) e pelo menos 5 linhas

Cenário 2: Contar Linhas

O que fazer: Contar quantas linhas de dados existem na tabela

Resultado Esperado: Deve haver pelo menos 5 linhas de dados

Cenário 3: Validar Formato de Email

O que fazer: Verificar todos os emails na coluna Email

Resultado Esperado: Todos os emails devem ter formato válido (contém @ e domínio)

Cenário 4: Validar Idade

O que fazer: Verificar todos os valores na coluna Idade

Resultado Esperado: Todas as idades devem ser números entre 18 e 100

Cenário 5: Validar Status

O que fazer: Verificar todos os valores na coluna Status

Resultado Esperado: Status devem ser apenas: "Ativo", "Inativo" ou "Pendente"

Cenário 6: Verificar Duplicatas

O que fazer: Verificar se há emails duplicados na tabela

Resultado Esperado: Não deve haver emails duplicados

Como Procurar Elementos

  • Tabela: data-testid="tabela-dados" ou table
  • Linhas de Dados: tbody tr
  • Coluna Email (2ª coluna): td:nth-child(2)
  • Coluna Idade (3ª coluna): td:nth-child(3)
  • Coluna Status (4ª coluna): td:nth-child(4)

Instruções Passo a Passo

  1. Acesse a página Tabela Dinâmica
  2. Verifique se a tabela existe e está visível na página
  3. Conte quantas linhas de dados existem (deve ser 5 ou mais)
  4. Percorra cada linha e verifique se o email tem formato válido (contém @)
  5. Verifique se todas as idades são números entre 18 e 100
  6. Verifique se os status são apenas: Ativo, Inativo ou Pendente
  7. Colete todos os emails e verifique se há duplicatas
  8. Verifique se não há células vazias na tabela

Exemplo de Automação

it('deve validar dados da tabela', () => {
  cy.visit('/pages/junior/tabelas/dynamic.html')
  
  // Conta linhas
  cy.get('tbody tr').should('have.length.at.least', 5)
  
  // Valida emails
  cy.get('tbody tr').each(($row) => {
    const email = $row.find('td:nth-child(2)').text()
    expect(email).to.include('@')
    expect(email).to.include('.')
  })
  
  // Valida idades
  cy.get('tbody tr').each(($row) => {
    const idade = parseInt($row.find('td:nth-child(3)').text())
    expect(idade).to.be.at.least(18)
    expect(idade).to.be.at.most(100)
  })
})
test('deve validar dados da tabela', async ({ page }) => {
  await page.goto('/pages/junior/tabelas/dynamic.html')
  
  const linhas = await page.locator('tbody tr').all()
  expect(linhas.length).toBeGreaterThanOrEqual(5)
  
  for (const linha of linhas) {
    const email = await linha.locator('td:nth-child(2)').textContent()
    expect(email).toContain('@')
    
    const idade = parseInt(await linha.locator('td:nth-child(3)').textContent())
    expect(idade).toBeGreaterThanOrEqual(18)
    expect(idade).toBeLessThanOrEqual(100)
  }
})

Desafio 3: Interação com Checkboxes e Radio Buttons

Objetivo: Testar a seleção e deseleção de checkboxes e radio buttons, validando estados e comportamentos.

Regras de Negócio

Checkboxes:
  • Permitem múltiplas seleções simultâneas
  • Podem ser selecionados e deselecionados independentemente
  • Cada checkbox é independente dos outros
Radio Buttons:
  • Permitem apenas uma seleção por grupo (mesmo atributo name)
  • Ao selecionar um radio, os outros do mesmo grupo são automaticamente desmarcados
  • Não podem ser desmarcados clicando novamente

Cenários de Teste

Cenário 1: Selecionar Checkbox

O que fazer: Clicar em um checkbox desmarcado

Resultado Esperado: Checkbox fica marcado

Cenário 2: Deselecionar Checkbox

O que fazer: Clicar novamente em um checkbox marcado

Resultado Esperado: Checkbox fica desmarcado

Cenário 3: Múltiplos Checkboxes

O que fazer: Selecionar 3 checkboxes diferentes

Resultado Esperado: Todos os 3 checkboxes ficam marcados simultaneamente

Cenário 4: Radio Button - Exclusividade

O que fazer: Selecionar 1º radio, depois selecionar 2º radio do mesmo grupo

Resultado Esperado: 1º radio é desmarcado automaticamente, apenas 2º fica selecionado

Cenário 5: Radio Button - Não Desmarcar

O que fazer: Com um radio selecionado, clicar novamente no mesmo radio

Resultado Esperado: Radio permanece selecionado (não pode ser desmarcado)

Como Procurar Elementos

  • Checkbox: input[type="checkbox"] ou data-testid="checkbox-aceite"
  • Radio: input[type="radio"] ou input[name="genero"]
  • Verificar estado: element.is_selected() (Selenium) ou element.checked (JavaScript)

Instruções Passo a Passo

Teste de Checkboxes:
  1. Acesse a página Checkboxes
  2. Clique em um checkbox → Verifique que fica marcado
  3. Clique novamente no mesmo checkbox → Verifique que fica desmarcado
  4. Selecione 3 checkboxes diferentes → Todos devem estar marcados
Teste de Radio Buttons:
  1. Acesse a página Radio Buttons
  2. Clique em um radio → Verifique que fica marcado
  3. Selecione outro radio do mesmo grupo → O primeiro deve ser desmarcado automaticamente
  4. Clique novamente no radio selecionado → Deve permanecer selecionado

Desafio 4: Seleção em Dropdown List

Objetivo: Testar a seleção de opções em um dropdown (select), validar valores e comportamento.

Regras de Negócio

  • Opção Padrão: Dropdown deve ter uma opção padrão (geralmente "-- selecione --")
  • Seleção Única: Apenas uma opção pode estar selecionada por vez
  • Valor vs Texto: Cada opção tem um value (dado) e um text (exibido)
  • Mudança de Seleção: Ao selecionar nova opção, a anterior é substituída

Cenários de Teste

Cenário 1: Verificar Opções Disponíveis

O que fazer: Abrir o dropdown e contar quantas opções existem

Resultado Esperado: Deve haver pelo menos 3 opções válidas

Cenário 2: Selecionar Primeira Opção

O que fazer: Selecionar a primeira opção válida

Resultado Esperado: Opção é selecionada e valor/texto estão corretos

Cenário 3: Selecionar Última Opção

O que fazer: Selecionar a última opção disponível

Resultado Esperado: Última opção é selecionada corretamente

Cenário 4: Mudar Seleção

O que fazer: Com uma opção selecionada, selecionar outra diferente

Resultado Esperado: Seleção anterior é substituída pela nova

Como Procurar Elementos

  • Dropdown: select ou data-testid="select-pais"
  • Todas as opções: select option
  • Opção selecionada: select option:checked
  • Valor selecionado: select.value

Instruções Passo a Passo

  1. Acesse a página Dropdown List
  2. Abra o dropdown e conte quantas opções existem
  3. Observe qual opção está selecionada por padrão
  4. Selecione a primeira opção válida → Verifique valor e texto
  5. Selecione a última opção → Verifique valor e texto
  6. Selecione uma opção do meio → Verifique valor e texto
  7. Com uma opção selecionada, selecione outra → Verifique substituição
